# 🌌 Gokul P Jith — Cyberpunk Aurora Portfolio (2026)

> A futuristic, high-performance personal developer portfolio built with React, Vite, Framer Motion, and modern glassmorphism. Featuring interactive 3D layered animations, an authentic cyber hacking terminal boot screen, and an arcade easter egg.

---

## ⚡ Live Features

- **Cyber Hacking Terminal Loader**: Matrix digital rain canvas, CRT scanline effects, synthetic Web Audio click sounds, and streaming diagnostic logs with manual skip/reboot triggers.
- **3D Flip Profile & Secret Arcade Game**: Interactive 3D perspective flip card that rotates 180° on click to reveal a playable retro **Cyber Snake** mini-game with score tracking, Web Audio sound effects, and keyboard/touch D-pad controls.
- **Layered Animated Cards**: Multi-plane elevation system featuring 3D mouse parallax tilt tracking, ambient dynamic back-glows, specular cursor spotlights, and cybernetic corner accents.
- **Dynamic Skills Domain**: Infinite tech marquee, domain filter tabs, energy gauge meters, and an interactive live skill inspector.
- **Full Showcase**: Highlighted work experience at Techmaghi (Data Science & ML Intern), flagship project *NutriDecide*, and academic achievements from APJ Abdul Kalam Technological University & FOSS FEST 2025.

---

## 🛠️ Tech Stack

- **Core**: React 18, Vite
- **Animations & Depth**: Framer Motion (3D Springs, Multi-plane Staggering)
- **Styling**: Vanilla CSS3, Glassmorphism, TailwindCSS utilities
- **Icons**: Lucide React
- **Audio Synthesis**: HTML5 Web Audio API Oscillators (Zero external audio assets)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/gokulpjith/Gokul-portfolio.git
cd Gokul-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
